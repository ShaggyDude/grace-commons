# Atomic Patterns

The freestanding concepts of Grace Commons. Each atomic pattern's specification can be stated without naming any other pattern. Atoms are organized by domain category.

For compositions of atoms, see [Compositions](../compositions/).

## Categories

- **Productivity** — patterns for recording, tracking, ordering, and completing units of work.
- **Temporal** — patterns governing windows, expiry, scheduling, and time-ordered logs.
- **Compliance** — patterns for audit trails, regulatory holds, reporting, and consent.
- **Resource Lifecycle** — patterns governing reservation, allocation, hold, commit, and release.

Each category README lists current and forthcoming atoms. The library is early; categories grow as patterns land.
