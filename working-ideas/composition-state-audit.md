# Composition-state audit matrix — provisional (2026-06-10)

> **Status: internal staging, not canonical.** Provisional classification of every grounded composition's Application-state elements against the composition-state rule adjudicated 2026-06-10 (`execution-contract.md` §Composition state: derivable → derived index; non-derivable → extracted atom; history-shaped memory → compose Event Log). Produced in the Refactor 1 session from the specs' own Application-state text, **without** per-composition audit rounds — every verdict below except the two settled poles is provisional until the audit wave's touch-triggered re-pass folds the classification into the owning spec. Tracked as ROADMAP methodology debt #9. This file dies into the patterns' Application state subsections and Lineage notes as the folds land.

Verdict vocabulary:

- **derived-index** — every fact rebuildable from constituent stores through declared read surfaces; the fold names the rebuild procedure.
- **extraction-pending** — carries truth no constituent store holds; the fold flags it and names the proposed atom.
- **re-house-on-Event-Log** — history-shaped memory (attempt logs, lifecycle journals) that the Contract's existing rule already assigns to a composed Event Log rather than a composition store.
- **audit-needed** — the classification turns on a fact the spec text alone does not settle (usually: whether the corresponding substrate/Event-Log write is atomic with the truth it would replay, or whether event `data` payloads carry the fields the rebuild needs). Lean recorded.
- **none / conforming** — no stored Application state (pure derived queries, or explicit None).

## Reading the matrix

Counts (provisional): 2 settled poles; ~19 lean derived-index; 3 strong audit cases that will shape the rubric (C9 `slot_released`; C4 `chain_store`; C17 binding maps); 4 re-house-on-Event-Log candidates (attempt/lifecycle journals); 4 none/conforming. The recurring decisive fact is the same almost everywhere: **does the event/audit write commit atomically with the truth it would replay, and does its `data` carry the fields a rebuild needs?** Where yes, the element is a derived index and the fold is cheap. Where no, the element carries truth and the choice is extraction vs. re-housing vs. tightening the event payload — a per-pattern decision for the audit round, not this matrix.
