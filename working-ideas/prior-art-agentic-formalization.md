# Prior-art / reading note — Agentic LLM Requirement Formalization

_Working staging, not canonical. A reading brief on an adjacent paper, with the five method takeaways to adopt. Lands into spec-format / pressure-testing / execution-contract as the adoptions are worked._

**Source:** *Towards an Agentic LLM-based Approach to Requirement Formalization from Unstructured Specifications* (Tagliaferro et al., Politecnico di Milano), arXiv:2604.18228v1 — https://arxiv.org/html/2604.18228v1

**Context for you:** NL → formal-property pipeline (extract → verifiability-filter → translate to UPPAAL SMC queries). Adjacent to Grace Commons but pointed the opposite way (they start from prose; we start from canonical `.intent.md`). Read for method, not their percentages — the headline 77.8% leans heavily on an LLM-as-judge and the study is thin (n=3, one model, no repetitions). Adopt only the following:

1. **Per-atom verifiability gate.** Add an explicit, traceable classification *before* attempting formal derivation: for each atom/composition, record whether it's verifiable and, if not, *why* (unobservable, qualitative intent, model-external) and *in which tool* it could be. Make it a field in the spec schema, not an implicit consequence of the Stated/Checked/Proved ladder.
2. **Separate "intent-aligned" from "well-formed" on the ladder.** Their data shows a large gap between "compiles / internally consistent" (95.8%) and "faithfully means the intent" (77.8%). Ensure the Checked rung doesn't silently conflate well-formedness with intent-alignment; treat semantic fidelity as its own check.
3. **Mechanize equivalence; never judge it.** They grant "semantic equivalence" credit via LLM judge for things (commutativity, A⟹B ≡ ¬A∨B, spatial symmetry) they admit are deterministically rewritable. Rule for us: anywhere Alloy/TLA+ can mechanically decide equivalence, it must — the Proved rung stays tool-grounded. An LLM judge is never load-bearing for assurance.
4. **Decoupled per-stage validation.** They evaluated each pipeline stage against a known-good intermediate to stop cascading errors masquerading as downstream failures. Apply to the derivation chain (spec → Alloy → TLA+ → Isabelle) and especially to Evergreen Modernization: validate each render target against the canonical layer independently, not end-to-end, so regressions localize.
5. **Harden the canonical spec against the two known extraction failure modes.** LLMs reliably (a) drop strict logical boundaries — termination, completion guarantees, failure detection — and (b) invent plausible-but-unstated constraints from domain priors. The human-authored canonical layer must explicitly carry the boundaries in (a), and pressure-testing must actively hunt (b). This is empirical support for the existing grounding-threshold and adversarial-posture discipline; keep both.

**Narrative bonus (not a process change):** their RQ1 recall was 60.6% — they *lost 39% of ground-truth requirements* as the direct cost of having no disambiguated canonical layer. That's a citable, quantified argument for the `.intent.md` canonical-first architecture. Usable in the grant narrative and the Jackson conversation.
